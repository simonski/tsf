# Projects

Create additional projects in the system.

Format: `name | description | repository | status | visibility`

```
backend-api | Backend REST API service | https://github.com/org/backend-api | active | public
frontend-app | Frontend React application | https://github.com/org/frontend-app | active | public
mobile-app | Mobile application | https://github.com/org/mobile-app | active | internal
infrastructure | Infrastructure as code | https://github.com/org/infrastructure | active | private
documentation | Project documentation | | active | public
```
